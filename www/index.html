RS485 (GPIO17/18)

How long a device may take to answer before it is reported as not responding. The Modbus serial specification leaves this to the application and calls 1 s to several seconds typical at 9600 baud; lower it only for a segment you know is faster.

Modbus TCP (port 502)

Modbus TCP has no password. Anything that can reach this device can read its inputs and switch its outputs — and, with RS485 set to master, everything on the RS485 segment as well. Only enable it on a network you control.

Read other Modbus TCP devices

Each row is one value this device fetches by itself. It is published on MQTT as modbus/<name> and is readable in a rule as mqtt('modbus/<name>') — that works even with no broker configured. Reading only; nothing is ever written to the other device. Network time (SNTP)

When enabled, the system clock is synced from this server and mirrored to the battery-backed RTC. NTP takes precedence over the RTC. Saved with the rest of the configuration.

Automation Rules

JavaScript rule script — changes are saved to the device and applied immediately without reboot. Leave empty and save to revert to the built-in demo. See the rule language reference.

DSL reference 
// Subscribe to an MQTT topic:
var t = mqtt('rules/trigger').is(function(m) { return m === 'ON'; });

// Read a digital input state:
var di0 = input(0).is(false);   // true when DI0 is open (not conducting)

// Define a rule:
rule('my-rule')
  .when(t, di0)               // all conditions must be true
  .then(function() {
    output(0).set(true);      // set digital output 0
    print('fired!');          // logs to the ESP console
  });
